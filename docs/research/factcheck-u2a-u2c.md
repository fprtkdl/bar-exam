# 팩트체크 u2a(t1~t3) + u2c(t7)

검토: 문항 76개(u2a 58, u2c 18) + 노트 2개. 정답 사전 풀이 후 대조.

## 수정 목록
없음. 정답 오류, 복수 정답, 해설-정답 불일치, 노트-문항 모순 모두 발견하지 못함.

## 의심 항목 확인
- u2-t1-q12, q16 / 노트 주세법: 주세법상 주류 = 주정 + 알코올분 1도 이상 음료. 증류주류에 소주·위스키·브랜디·일반증류주·리큐르 포함, 발효주류는 탁주·약주·청주·맥주·과실주. 알코올분은 15도 기준. (PwC 요약 https://www.pwc.com/kr/ko/insights/industry-focus/samilpwc_k-alcohol-drink.pdf , 법령 https://www.law.go.kr 주세법 — law.go.kr 원문 직접 열람은 실패하여 검색 요약과 기억에 의존)
- u2-t1-q14: 알렘빅은 아랍어 al-anbiq 에서 온 말로 중세 아랍 연금술사가 발전. 일반 상식, 이견 없음.
- u2-t2-q10: 카비네트 < 슈페트레제 < 아우슬레제 < 베렌아우슬레제 가 정답 선택지. 아이스바인은 선택지에 없어 위치 논쟁 무관(노트는 BA < 아이스바인 < TBA, 통용 표기).
- u2-t3-q18: 1516 바이에른 순수령 = 보리·홉·물(효모는 이후). 통설.
- u2-t7-q03, q18: 셀처(독일 Selters 유래)·비시·페리에 탄산, 에비앙·볼빅 무탄산. 통설.
- 노트: 로부스타 콩고(중앙아프리카) 원산, 로스팅 8단계(라이트-시나몬-미디엄-하이-시티-풀시티-프렌치-이탈리안), 에스프레소 9기압/90~95℃/20~30초/25~30ml 모두 통용 교재값과 일치.

## 보류 목록
없음. 참고: 로스팅 단계 명칭·에스프레소 수치는 교재마다 약간 다를 수 있으나 문항 정답(시티 다음 = 풀시티, 약 9기압)은 공통.
