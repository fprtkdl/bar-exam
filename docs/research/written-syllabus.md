# 조주기능사 필기 출제기준 조사 (조회일 2026-11-12)

## 시험 형식 (Q-net 확인)
- 시행처 한국산업인력공단. 필기 과목: 음료특성, 칵테일 조주 및 영업장 관리 (바텐더 외국어 사용 포함)
- 객관식 4지 택일형 60문항 / 60분 / 100점 만점 60점 이상 합격. 실기: 바텐더 실무 (작업형 7분)
- 출처: https://www.q-net.or.kr/crf005.do?id=crf00503s01&gSite=Q&gId=&jmCd=7916 (직접 조회, 2026년 시험일정도 게시 중)

## 적용 기간과 확인 수준 (주의)
- **원문을 직접 읽은 기준: 출제기준(필기) 적용기간 2022.1.1~2024.12.31** (HWP 원문 파싱). 출처: https://www.msu.ac.kr/foodstartup/board/read?boardManagementNo=1582&boardNo=603&menuLevel=2&menuNo=790 (첨부 `조주기능사(2022.1.1~2024.12.31).hwp`, 공단 기준 사본)
- 2025.1.1 이후 적용본(현행)의 원문은 **확보하지 못함**: Q-net 자료실은 동적 페이지라 직접 조회 불가, 검색으로도 원문 없음. 다만 Q-net 종목 페이지의 현행 시험과목·문항·시간·합격기준은 위 기준과 동일하다. 확인 수준 = Q-net(형식) + 2022~2024 원문(구조). 현행본과 세세항목 차이 가능성이 있으므로 **Q-net 출제기준 자료실에서 최종 대조 필요**.
- 2차 자료(수험서 목차 요약, 나무위키)는 구조 참고만 했고 기준으로 삼지 않았다.

## 출제기준 원문 요약 (2022.1.1~2024.12.31, 필기)
1. **위생관리**: 음료 영업장 위생 관리(영업장 위생 확인) / 재료·기물·기구 위생 관리 / 개인위생 관리 / 식품위생 및 관련법규(위생적 주류 취급 방법, 주류판매 관련 법규)
2. **음료 특성 분석**: 음료 분류(알코올성·비알코올성) / 양조주 특성(개념, 분류·특징, 와인 분류·특징, 맥주 분류·특징) / 증류주 특성 / 혼성주 특성 / 전통주 특성(특징, 지역별) / 비알코올성 음료 특성(기호·영양·청량) / 음료 활용(알코올성·비알코올성·부재료) / 음료의 개념과 역사
3. **칵테일 기법 실무**: 칵테일 특성 파악(역사, 기구 사용, 분류) / 칵테일 기법 수행(셰이킹·빌딩·스터링·플로팅·블렌딩·머들링·그 밖의 기법)
4. **칵테일 조주 실무**: 칵테일 조주(종류별 특징, 레시피, 얼음 종류, 글라스 종류) / 전통주 칵테일 조주(표준 레시피) / 칵테일 관능평가
5. **고객 서비스**: 고객 응대(예약 관리, 응대 매뉴얼, 불만 처리) / 주문 서비스(메뉴 종류와 특성, 주문 접수) / 편익 제공(서비스 용품·시설) / 술과 건강(술이 인체에 미치는 영향)
6. **음료영업장 관리**: 시설 관리(점검, 유지보수, 배치) / 기구·글라스 관리 / 음료 관리(구매·재고·원가)
7. **바텐더 외국어 사용**: 기초 외국어 구사(음료·접객 서비스) / 영업장 전문용어(시설물·기구) / 알코올성 음료 외국어 표현 / 비알코올성 음료 외국어 표현
8. **식음료 영업 준비**: 테이블 세팅(영업기물별 취급) / 스테이션 준비(기물, 비품·소모품) / 음료 재료 준비(준비, 보관) / 영업장 점검(시설물 유지관리)
9. **와인장비·비품 관리**: 와인글라스 유지·관리(용도별 사용) / 와인비품 유지·관리(와인 용품 사용)

## 사이트 단원 구성 (주요항목 9 -> 단원 8)
- 8번(식음료 영업 준비)과 9번(와인장비·비품 관리)은 각각 필기 세세항목이 3~5줄로 매우 작아 **하나의 단원 u8 로 합침**. 나머지는 주요항목 = 단원.
- 2번(음료 특성 분석)은 범위가 커서 토픽 7개(개념·역사·분류 / 와인 / 맥주·기타 / 증류주 / 혼성주 / 전통주 / 비알코올·활용)로 분할. 원문 "음료의 개념과 역사"는 분류와 묶음.
- 토픽은 세부항목 수준. 4번의 "칵테일 조주 실무"에서 레시피(표준 40품목 계열)가 핵심이라 별도 토픽.

- 결과: **원문 미확보 (미확인)**. 구성상 차이도 확인 불가 — syllabus.ts 는 2022~2024 원문 기준 그대로.
- 시도: 검색어 `조주기능사 출제기준 2025.1.1 2027.12.31`, `"조주기능사 출제기준" q-net 자료실`, `조주기능사 출제기준 개정 2025 ...` 등. Q-net 자료실(https://q-net.or.kr/cst006.do?id=cst00602) 상세 글은 다른 종목(가구제작산업기사 5213398, 기중기운전기능사 5213177, 농기계정비기능사 5213405: 2025.1.1~2027/2028.12.31)만 노출되고 조주기능사 글은 검색에 안 잡힘. 자료실 목록은 동적이라 WebFetch 로 열리지 않음. data.go.kr 기능사 종목별 시험정보(3073411)에는 출제기준이 없음. 공부해닷컴은 2013~2017 판만 게시.
- 2차 출처 1건(https://winter.sparklinghee.com/entry/2025-%EC%A1%B0%EC%A3%BC%EA%B8%B0%EB%8A%A5%EC%82%AC-%EC%9B%90%EC%84%9C%EC%A0%91%EC%88%98-%EB%B0%A9%EB%B2%95 )이 "조주기능사 (2025.1.1 ~ 2027.12.31)" 를 적용기간으로 적고 필기과목을 "음료특성, 칵테일 조주 및 영업장 관리 (바텐더 외국어 사용 포함)" 로 적음. 과목명은 Q-net 종목 페이지와 같다. 개인 블로그라 원문 근거로는 불충분 — **미확인** 으로 둔다.
