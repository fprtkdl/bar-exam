## 수정 목록
- u1-t4-q10 해설, u1 노트(국민건강증진법 행): 경고문구를 "과다한 음주는 건강에 해롭다" 등 실제 고시와 다른 문장으로 적었음 → 고시 계열 문구(뇌졸중·치매·암 / 기형아 출생 위험)로 정정. 정답·보기는 그대로.
- u1 노트 노로바이러스: "85℃" → "중심온도 85℃" (식약처 표현).
- u5-t4-q07 해설, u5 노트: 위 20% 에 "문헌에 따라 20~30%" 병기. 정답 불변.

## 보류 목록 (수정 안 함)
- u5-t1-q09 (MTP), u5-t1-q10 해설: 출처 미확인. 정답은 사람·시간·장소(Man·Time·Place) 로 한국 서비스 교재에서 흔하다고 알려져 있으나 웹 근거 없음. 수험서로 확인 필요.
- u5-t2-q05 (주문 순서): 출처 미확인, 교재에 따라 다를 수 있어 "가장 적절한 것" 논쟁 소지. 교재 대조 후 삭제/교체 권장.
- u1-t2-q12: 5~60℃ 가 4~60℃ 로 쓰이는 출처도 있음. 정답 자체는 안정.
- u1-t2-q11: "2023.1.1" 은 시행일이며 1년 계도·우유류 2031 예외가 있음. 정답 안정.
- u1-t3-q02/q03/q05, u1-t4-q06/q08, u5-t4-q06/q08: 2차 출처 기준 일치. 법제처 원문 대조 권장.
