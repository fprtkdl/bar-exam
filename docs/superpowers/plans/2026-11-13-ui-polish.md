## §0 원칙

1. **브라우저·OS 기본 모양 0.** 아래가 화면에 보이면 결함이다: 기본 `<select>` 와 그 옵션 팝업, 기본 드롭다운 화살표, `<details>` 기본 삼각형, 기본 체크박스·라디오, 검색창 기본 지우기(×) 버튼, 파일 선택 기본 버튼, 기본 스크롤바(안쪽 스크롤 영역), 기본 파란 탭 하이라이트·기본 선택 색, 기본 링크 밑줄 색.
2. **글리프·이모지 아이콘 금지.** `▶ ▸ ▼ ‹ › → ✓ ✗ × ★` 같은 문자나 이모지(🍸 💡 등)를 아이콘으로 쓰지 않는다(글꼴·OS 마다 모양이 달라진다). 전부 `Icon` 컴포넌트(§1)로 바꾼다. 문장 안의 화살표 문자("셰이크 → 빌드")도 `Icon` 또는 가운뎃점(·)으로.
3. **같은 것은 같은 자리에.** 카드 목록에서 같은 종류의 정보(배지·메타)는 모든 카드에서 같은 위치·같은 줄 수에 있어야 한다. 내용 길이에 따라 줄 수가 달라지는 배지 나열 금지 — 라벨:값 행, 고정 칸, 말줄임으로 해결.
4. **상태가 보이게.** 누를 수 있는 것은 hover·focus-visible·active(눌림: 2px 이동 + 그림자 사라짐)·disabled·selected 상태를 모두 갖는다. 카드 전체가 링크면 카드에도 동일하게.
5. **간격 리듬.** 간격은 4·8·12·16·24·32px 만. 카드 안쪽 여백은 모바일 16 / 데스크톱 20. 섹션 사이 32. 같은 화면에서 카드 테두리·그림자·모서리 값은 하나(`border-2 border-ink`, `shadow-pixel`, `rounded-pixel`).
6. **모바일 먼저 확인.** 390px 에서 가로 스크롤 0, 터치 대상 44px 이상, 하단 탭 바에 내용이 가리지 않음.
7. 접근성 유지: 키보드로 전부 조작, `aria-*` 상태, 색만으로 구분하지 않기, `prefers-reduced-motion`.

## §1 공용 기반 — P1 이 만들고 나머지가 쓴다 (`src/ui`, `src/styles`, `src/app`)

| 이름 | 역할 |
|---|---|
| `Icon` | 인라인 SVG 아이콘 세트. 16×16 격자, `currentColor`, 픽셀 느낌(직선·계단, `shape-rendering="crispEdges"`). 이름: `chevron-down` `chevron-right` `chevron-left` `arrow-right` `check` `x` `search` `flag` `clock` `tip` `star` `refresh` `download` `upload` `trash` `book` `pencil` `glass` `shaker` `gear` `home` `chart` `note` `play`. props: `name`, `size?`(기본 16), `className?`, `label?`(없으면 `aria-hidden`). |
| `Select` | 기본 `<select>` 대체. 트리거 버튼(값 + `chevron-down`) + 팝오버 리스트박스(카드 스타일, 선택 항목에 `check`). props: `label`(시각 라벨 또는 `aria-label`), `value`, `onChange(value)`, `options: { value: string; label: string }[]`, `className?`. 키보드: ↑↓ Home End Enter Space Esc, 글자 입력으로 이동. 바깥 클릭·Esc·Tab 으로 닫힘. `aria-haspopup="listbox"`, `aria-expanded`, `role="listbox"`/`option`, `aria-selected`. 팝오버는 화면 아래가 모자라면 위로, 긴 목록은 max-height + 스타일된 스크롤. |
| `ChipGroup` | 선택지 5개 이하의 단일 선택(정렬·모드 등). `role="radiogroup"`, 방향키 이동. props: `label`, `value`, `onChange`, `options`. |
| `Checkbox` | 픽셀 체크 상자 + 라벨. 내부는 진짜 `<input type="checkbox">`(시각적으로 숨김). props: `checked`, `onChange(checked)`, `disabled?`, `children`. |
| `Disclosure` | 접기/펼치기. `<details>/<summary>` 를 쓰되 기본 삼각형을 숨기고 `chevron-right` 가 회전. props: `summary`, `defaultOpen?`, `children`. |
| `SearchInput` | `search` 아이콘 + 입력 + 값이 있으면 `x` 지우기 버튼. props: `value`, `onChange(value)`, `placeholder`, `label`. |
| `TextField` 스타일 | 텍스트 입력 공통 클래스 `inputClass`(2px 잉크 테두리, 모서리, 종이 배경, focus 링). |
| `PageLoading` | 라우트 로딩 표시(픽셀 점 3개 깜빡임, `role="status"`). Layout 의 Suspense fallback. |
| `Card` | `interactive` prop 추가: hover(−1px 이동 + 그림자 유지) · active(눌림) · focus-visible 링. |
| 전역 CSS | 검색창 기본 지우기 버튼 숨김, `summary` 기본 표식 숨김, 스크롤바(얇게, 잉크 색 thumb, 투명 track — Firefox `scrollbar-*` 와 WebKit 둘 다), `::selection`(butter), `-webkit-tap-highlight-color: transparent`, `button`/`a` 기본 모양 정리, `accent-color: var(--color-ink)`, 본문 링크 스타일. |
| Layout | 내비·하단 탭에 `Icon`(home·pencil·glass·shaker·gear), 하단 탭 `env(safe-area-inset-bottom)`, 라우트별 `document.title`(`<화면 이름> · 공부바`), 파비콘(인라인 SVG data URI — 픽셀 칵테일 잔)과 `theme-color`. |
| `/dev/ui` | 위 컴포넌트의 모든 상태를 한 화면에 늘어놓은 점검 페이지(`src/features/dev/UiGalleryPage.tsx`, routes 에 추가). |

### P3 실기 화면 — opus · 포트 5193

- 기본 UI 교체: 레시피 목록의 `<select>` 3개 → `Select`(기주·잔), `ChipGroup` 또는 `Select`(기법), 검색 → `SearchInput`. 글리프·이모지 → `Icon`.

- **레시피 상세**: 정보 표(기주·기법·잔·얼음·칠링·가니쉬)를 라벨 고정 폭 격자로, 재료 표 정렬, "만드는 순서" 번호 스타일, 이전/다음 레시피 이동.
